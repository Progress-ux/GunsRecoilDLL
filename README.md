# GunsRecoilDLL

## Clone repository

```bash
git clone https://github.com/Progress-ux/GunsRecoilDLL.git
cd GunsRecoilDLL
```

### Install Metamod-P
```bash
git clone https://gitlab.com/sven-coop-tools/metamod-p.git
```

### Install ReGameDLL_CS
```bash
git clone https://github.com/s1lentq/ReGameDLL_CS.git
```

## Make library
```bash
cmake -S . -B build
cmake --build build
```
